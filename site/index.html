SEED-DRIVEN WORLD SIMULATION

让世界演化，
可以复现。

万象是一套以 Rust 编写的实验性世界模拟引擎。给定种子和规则，推进世界状态，观察角色、势力、事件与资源账本如何变化，再对照不同规则下的模拟轨迹。

查看模拟结果 ↓阅读项目代码 ↗
A REPRODUCIBLE EXPERIMENT
seed → rules → world

演示数据在网站构建阶段由 Rust SDK 实际运行生成。浏览器只展示真实导出结果，不用随机数字伪装模拟内核。

实时 Rust 引擎 DISCONNECTED

连接独立运行的 Rust 服务后，页面读取真实 WorldModel 状态。静态快照只是默认展示；实时推进与规则实验都由后端执行。

模拟旅行 ROUTE-AWARE SIMULATION

规划代价包含距离、高差、地形、危险度及角色能力。旅行会推进世界 tick、扣除抽象补给、按确定性规则生成遭遇事件，并记录每一段到达事件；不可达路线或补给不足时会拒绝出发。操作需要连接实时 Rust API。

连接实时服务并加载含地点路线的世界快照后，可执行旅行；旅行时间、风险、遭遇和补给变化会写入持久化快照。

04 / HOW IT RUNS
静态展示与实时 Rust 服务
GitHub Pages 负责静态展示；实时模式连接单独运行的 Rust API，并直接调用同一套 wanxiang_sdk::WorldModel。没有连接 API 时页面仍会退回构建时生成的快照。


构建与部署 NO RENTED SERVER
模拟计算GitHub Actions 构建时
静态页面GitHub Pages 托管
实时 Rust API可本地运行 / 容器部署
第三方模型 API无
GitHub Pages 本身不运行 Rust 后端。要启用上方实时控制，请启动 wanxiang_agent_bridge --example live_server，或部署 Dockerfile.live；服务端负责推进状态、持久化检查点、规则分支对照及可选 LLM 请求。

cargo run --locked -p wanxiang_sdk --example web_demo_data -- 42 100 > demo.json
