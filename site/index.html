SEED-DRIVEN WORLD SIMULATION

让世界演化，
可以复现。

万象是一套以 Rust 编写的实验性世界模拟引擎。给定种子和规则，推进世界状态，观察角色、势力、事件与资源账本如何变化，再对照不同规则下的模拟轨迹。

查看模拟结果 ↓阅读项目代码 ↗
A REPRODUCIBLE EXPERIMENT
seed → rules → world

演示数据在网站构建阶段由 Rust SDK 实际运行生成。浏览器只展示真实导出结果，不用随机数字伪装模拟内核。

核心语言Rust
托管形式静态网页

04 / HOW IT RUNS
没有服务器，也能发布
静态托管网站不需要租用云主机。GitHub Actions 构建阶段运行 Rust SDK 生成快照，页面只读取静态 JSON。


构建与部署 NO RENTED SERVER
模拟计算GitHub Actions 构建时
静态页面GitHub Pages 托管
持续运行后端无
第三方模型 API无
静态演示不能在后台持续推进世界、实现多人实时共享或保存云端存档；这些能力需要另行设计。


导入自己的模拟结果 LOCAL DATA
本地运行 SDK 导出真实规则对照 JSON，再通过上方按钮导入。文件只在当前浏览器读取，不会上传。
cargo run --locked -p wanxiang_sdk --example web_demo_data -- 42 100 > demo.json
或者粘贴 JSON
