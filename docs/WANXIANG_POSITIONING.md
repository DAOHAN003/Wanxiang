# 万象的定位与“活着”的工程含义

## 万象不是 Agent

万象的核心是一个可持续运行、可被检查和干预的世界模拟系统。Agent 是可接入这个环境的参与者之一：它可以观察世界、提交动作，再由世界规则计算动作后果。万象本身不等同于 Agent，也不要求必须存在 LLM 才能运行世界。

## “活着”的工程定义

在软件意义上，万象可以逐步具备“持续运行的世界”的性质：

- **连续状态**：世界拥有 tick、实体、事件和资源账本。
- **自主演化时钟**：服务端可在浏览器离开后继续推进 tick；设置手动模式时由调用者控制。
- **状态延续**：世界检查点和运行状态可以持久化，并在进程重启后恢复。
- **内部约束**：每一步可以检查声明的不变量、资源账本和状态边界。
- **可追溯历史**：通过事件、操作历史、种子和配置复现或比较轨迹。
- **可干预反馈**：规则和行动会影响后续世界状态。

这些工程属性可以让世界在服务持续运行期间“活起来”，但它们不证明万象是生物、具有意识、主观体验、内在欲望，或能够在没有设计者提供的规则下自我繁殖和无限自我改进。

## 万象与 Agent 的关系

- **世界内核**：负责世界状态、时间推进、规则执行和约束检查。
- **实验内核**：负责从同一初始条件建立基线和干预分支，运行实验、执行不变量检查并形成报告。
- **Agent 参与者**：可选的策略/模型，根据观察产生动作；其输出必须经过世界接口和规则校验。
- **研究与评测工具**：比较不同规则或 Agent 的轨迹，不把一次成功运行等同于普遍能力。

## 当前状态与边界

当前仓库已有 Rust 世界模拟 SDK、服务端自动 tick、运行状态持久化、规则分支/轨迹比较和受限 Agent 桥接。新增的 wanxiang_experiment 实验内核将这些基础中的规则分支、快照和对照实验组织成统一报告，并对种子、推进步数、抽象资源账本和固定种子回放做显式检查。

当前内置干预首先覆盖 energy_density。这不是完整的结构因果模型（SCM），也不构成现实因果识别。因果图算法、记忆检索和世界反馈仍应分别通过合成真值、基线比较、长程稳定性与真实任务评测验证。

万象当前是早期实验性世界模拟与智能体实验项目。它可以作为持续演化的数字世界运行，但不能因此宣称生物意义上的生命或意识。
