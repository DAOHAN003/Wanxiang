## 阅读建议 | Suggested reading order

1. New users: project overview → first experiment → product acceptance.
2. Integrators: project positioning → architecture → SDK examples in the repository.
3. Contributors: contributing guide → architecture and algorithm status → relevant tests.
4. Security reports: follow the private reporting path in `SECURITY.md`; do not publish exploitable details in a public issue.

文档描述的是仓库当前公开实现；实验组件的存在不代表它们已经全部集成或达到生产级成熟度。
